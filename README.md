# Mobile Phone Data Analysis

## Project Overview
This project focuses on collecting mobile phone data from Flipkart and performing data cleaning and Exploratory Data Analysis (EDA) using Python. The goal is to understand mobile phone specifications, pricing, and relationships between different features.

## Objectives
- Collect mobile phone data using web scraping.
- Clean the dataset and handle missing values.
- Convert columns into appropriate data types.
- Identify and remove duplicate records.
- Analyze price, RAM, ROM, display size, battery capacity, and ratings.
- Visualize data distributions and relationships between features.
